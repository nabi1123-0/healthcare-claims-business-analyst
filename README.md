# Healthcare Claims & Pricing Analysis
Business Analyst / Data Analyst Project

## Project Overview
This project simulates a real-world healthcare insurance analytics scenario where claims data is analyzed to support operational and pricing decisions. The goal is to identify cost drivers, utilization trends, and pricing insights that help healthcare organizations improve efficiency and control costs.

This project reflects responsibilities typically handled by Business Analysts and Data Analysts in healthcare environments such as insurance providers, health plans, and healthcare systems.

---

## Business Objectives
- Analyze healthcare claims data to identify high-cost procedures
- Compare claim costs across different insurance plan types
- Understand healthcare utilization trends
- Provide data-driven insights to support pricing and operational decisions

---

## Dataset
The dataset represents simulated healthcare insurance claims and includes the following fields:

- Member ID
- Plan Type (HMO, PPO, EPO)
- Claim Amount
- Procedure Category
- In-Network / Out-of-Network indicator
- Claim Date

---

## Tools & Technologies
- SQL (MySQL-style queries)
- Python (Pandas, NumPy)
- Excel (optional reporting)
- GitHub for version control

---

## Key Analysis Performed
- Total and average claim cost analysis
- Cost comparison by insurance plan type
- Identification of high-cost procedures
- In-network vs out-of-network cost analysis
- Claims trend analysis over time

---

## Business Impact
The insights from this analysis can help healthcare organizations:

- Identify high-cost procedures contributing to overall claims spend
- Understand cost differences between in-network and out-of-network services
- Support pricing strategy and cost management initiatives
- Improve healthcare utilization and operational decision-making
